# Research Roadmap

## Purpose

This document describes the long-term evolution of the Stock Screener Research Platform.

It is intentionally aspirational. It captures the intended research direction rather than a committed delivery schedule.

---

## Phase 1

Research Foundation

Complete / Substantially Complete

- Evaluation Profiles
- Reference Universe
- Opportunity Discovery
- Contract Quality Model
- SQLite Research Repository
- Study Protocols
- Export Instrumentation
- Scheduled Observation execution
- Research Dashboard protocol progress

---

## Phase 2

Cloud Continuous Observation Infrastructure

Planned

- Cloud scheduler
- Cloud research runner
- Cloud database

- Cloud-hosted dashboard or dashboard reading cloud data

---

## Phase 3

Research Characterization

Planned

- Technical Analysis Model v0.1 stock-level observations
- Technical Analysis Explorer v0.1 QA and observation view
- Security Characterization
- Excellent Contract Characterization
- Rule Characterization
- Near Miss Characterization
- Opportunity Concentration
- Security Passports

Technical Analysis Model v0.1 is a research-only layer. It persists underlying-security technical observations but does not filter, score, rank, or otherwise change Contract Quality Model or Opportunity Discovery behavior.

Technical Analysis Explorer v0.1 is the read-only UI surface for TAM QA. It displays persisted `technical_characterization` rows, summary counts, distributions, and missing-indicator checks without changing Opportunity Discovery, CQM scoring, rankings, thresholds, QED, or Evaluation Profile behavior.

## Guiding Principle

"The objective of the platform is not to predict markets. The objective is to characterize, measure, and improve analytical models through disciplined observation and accumulated evidence."
